# RIVA — прототип интерфейса (ПК)

Единый `index.html` с тестовыми данными, без базы. Спроектированы «Снабжение», «Склад», «Производство», «Продажи» и «Сотрудники»; «Клиенты» и «Финансы» — заглушки.

Исходники в `src/`, сборка: `node build.mjs` → `index.html`.

## Концепция и дизайн-страница

- `docs/concept.md` — концепция функционала (черновик документа «RIVA — концепция функционала.docx», сборка `node docs/build-concept-docx.cjs`): для кого, модель предприятия, цепочка документов, страницы, сквозные механики, модули после запуска.
- `design/overview.html` — страница «Обзор» в новом дизайне отдельным файлом (сборка `node design/build-overview.mjs` из `src/` и `design/`), прототип `index.html` не меняет: https://alchemist8931.github.io/riva-prototype/design/overview.html
